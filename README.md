# HTML5 Semantic Structure & Accessibility Portfolio

This project was created for the Thiranex task.

## Pages
- `index.html` — Home
- `about.html` — About
- `projects.html` — Projects
- `contact.html` — Accessible contact form
- `css/style.css` — Responsive styling

## Accessibility features
- Semantic HTML5 landmarks: header, nav, main, section, article, aside, footer
- Skip-to-content link
- Keyboard-focus styles
- Accessible navigation with `aria-label`
- Current page indicated with `aria-current`
- Proper form labels and required fields
- Useful `autocomplete` attributes
- Responsive design
- Reduced-motion preference support
- Good heading hierarchy
- Descriptive page titles and meta descriptions
